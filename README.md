# 청룡언월전 — 오호대장 무쌍

삼국지를 배경으로 한 횡스크롤 액션 게임입니다. HTML 파일 하나로 되어 있어 브라우저에서 바로 실행됩니다.

## 플레이
- `index.html`을 브라우저로 열거나, GitHub Pages 링크로 접속하세요.
- 조작: 이동 `← →` / `A D` · 점프 `↑` / `Space` / `K` · 공격(3연격) `Z` / `J` · 필살기 `X` / `L` (기력 50) · 일시정지 `P` · 소리 `M`
- 태블릿·휴대폰에서는 화면에 터치 버튼이 나옵니다. 휴대폰은 가로 화면으로 실행됩니다 (첫 터치 때 전체화면·가로 고정을 시도하고, 안 되면 화면을 눕혀서 보여줌).

## 장수
| 장수 | 특징 | 필살기 |
|---|---|---|
| 관우 운장 | 균형형 | 청룡파 — 초승달 참격을 날림 |
| 장비 익덕 | 느리지만 체력·힘 최고 | 장판교 일갈 — 호통으로 주변 적을 날림 |
| 조운 자룡 | 가장 빠르고 창이 긺 | 칠진칠출 — 적진을 꿰뚫는 돌진 |
| 황충 한승 | 3타째가 화살 | 백보천양 — 화살비 |
| 위연 문장 | 연속 공격형 | 반골 난무 — 다섯 번 몰아치는 연속 베기 |

## 이야기 (삼국지 전쟁 순서)
1. 황건적의 난 (184) — 정원지
2. 사수관 전투 (190) — 화웅
3. 백마 전투 (200) — 안량
4. 장판파 (208) — 문빙
5. 적벽대전 (208) — 허저
6. 정군산 전투 (219) — 하후연

## 폴더
- `index.html` — 최신 버전 (v3.0)
- `versions/` — 이전 버전들 (v1.0 관우 단독, v2.0 다섯 장수, v3.0 6장 스토리)
- `sprites/` — Gemini로 만든 원본 스프라이트 시트 (분홍 배경)
- `tools/` — 게임 소스(`game_src2.html`)와 스프라이트 자르기·빌드 스크립트 (PowerShell)
  - `grid.ps1`: 분홍 배경 시트를 격자로 잘라 아틀라스 PNG + JSON 생성
  - `build2.ps1 -out <파일>`: 아틀라스와 소스를 합쳐 HTML 한 파일로 빌드

## 진행 중
- 배경 6장은 아직 코드로 그린 임시 배경입니다 (Gemini 픽셀아트 배경으로 교체 예정).
- 4~6장 보스(문빙·허저·하후연)는 기존 보스 그림의 색을 바꾼 임시 그림입니다.
