# 청룡언월전 — 오호대장 무쌍

삼국지를 배경으로 한 횡스크롤 액션 게임입니다. HTML 파일 하나로 되어 있어 브라우저에서 바로 실행됩니다.

## 플레이
- `index.html`을 브라우저로 열거나, GitHub Pages 링크로 접속하세요.
- 조작: 이동 `← →` / `A D` · 점프 `↑` / `Space` / `K` · 공격(3연격) `Z` / `J` · 필살기 `X` / `L` (기력 50) · 군영에서 고르기 `↑ ↓` · 일시정지 `P` · 소리 `M`
- 태블릿·휴대폰에서는 화면에 터치 버튼이 나옵니다. 휴대폰은 가로 화면으로 실행됩니다 (첫 터치 때 전체화면·가로 고정을 시도하고, 안 되면 화면을 눕혀서 보여줌).

## 장수와 무기
| 장수 | 무기 | 공격 | 기본 필살기 | 구매 필살기 (3000P / 6000P) |
|---|---|---|---|---|
| 관우 운장 | 청룡언월도 | 묵직한 3연격 | 청룡파 | 회전 청룡참 / 청룡강림 |
| 장비 익덕 | 장팔사모 | 멀리 닿는 찌르기 | 장판교 일갈 | 사모 난격 / 대지 진동 |
| 조운 자룡 | 청강검 | 빠른 4연격 + 검기 | 칠진칠출 | 검기 연참 / 백룡승천 |
| 황충 한승 | 보조궁 | 모든 공격이 화살 (3타 = 세 발) | 백보천양 | 관통 화살 / 화살비 |
| 위연 문장 | 대도 | 연속 공격형 | 반골 난무 | 회전 대도 / 낙뢰 일섬 |

## 군공 포인트와 군영
- 적 20P · 정예병 80P · 적장 1000P · 장 클리어 1500P
- 장을 깰 때마다 **군영**에 들러 정비합니다.
  - 무기 강화 ★1~★5 — 단계마다 공격력 +25%, 무기 빛깔이 바뀌고 ★4부터 화살이 관통
  - 필살기 구매·장착 (장수마다 3가지)
  - 최대 체력 +20 (3번), 군량 보급 (체력 회복)
- 군영에 들어갈 때 자동 저장 → 타이틀에서 **이어하기**

## 이야기 (30장, 삼국지 전쟁 순서)
황건적의 난 → 광종 → 사수관 → 호로관 → 서주 → 하비성 → 백마 → 연진 → 오관 돌파 → 고성 → 박망파 → 신야 → 장판파 → 적벽대전 → 화용도 → 남군 → 장사 → 낙봉파 → 가맹관 → 성도 → 정군산 → 한수 → 양평관 → 번성 → 맥성 → 이릉 → 남만 정벌 → 독룡동 → 가정 → **오장원 (최종 보스 사마의)**

뒤로 갈수록 적이 많고 강해집니다. 전용 그림이 없는 적장은 기존 보스 그림의 색을 바꿔 씁니다.

## 폴더
- `index.html` — 최신 버전 (v4.1)
- `versions/` — 이전 버전들 (v1.0 관우 단독, v2.0 다섯 장수, v3.0 6장 스토리, v3.1 Gemini 배경·4~6장 보스 그림, v4.0 장수별 무기·군영·30장)
- `sprites/` — Gemini로 만든 원본 스프라이트 시트 (분홍 배경)와 배경 원본 그림
- `tools/` — 게임 소스(`game_src2.html`)와 스프라이트 자르기·빌드 스크립트 (PowerShell)
  - `grid.ps1`: 분홍 배경 시트를 격자로 잘라 아틀라스 PNG + JSON 생성
  - `build2.ps1 -out <파일>`: 아틀라스와 배경(`bg_<테마>.jpg` + `bg_meta.json`)을 소스와 합쳐 HTML 한 파일로 빌드
  - `bg.ps1`: 배경 그림을 540px 높이 JPEG로 변환
  - `build.py <파일>`: `build2.ps1`과 같은 빌드를 파이썬으로
  - `grid.py`: `grid.ps1`과 같은 그림 자르기를 파이썬으로
